# Security

Report a vulnerability in [GitHub issues](https://github.com/Xanadupia/xrayviewer/issues) or by email to the address on Ali Qaryan's GitHub profile.

Leave out tokens, private keys, and private diffs. X-RayViewer refuses to post a review that looks like it contains one, and a report should too.

Agents run on your computer, under the account of the program you picked. A pull request's own hooks and rules do not run. The only write to GitHub is the review you post.
